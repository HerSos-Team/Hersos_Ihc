# HerSos – Plataforma de Seguridad para Mujeres

HerSos es una solución digital orientada a brindar apoyo y protección a mujeres en situaciones de riesgo mediante un botón de pánico, alertas de emergencia y funciones de geolocalización.

## 🚨 Segmento objetivo
- Mujeres que se desplazan solas en espacios públicos.
- Mujeres que pueden estar expuestas a situaciones de riesgo.
- Personas que buscan una herramienta rápida y accesible para pedir ayuda.

## ⭐ Características principales
- Activación del **botón de pánico** mediante:
  - Un gesto rápido (doble toque, deslizamiento, etc.)
  - Un botón visible en la interfaz
- Envío de alertas automáticas a:
  - Contactos de emergencia
  - Instituciones correspondientes (según diseño futuro)
- **Geolocalización en tiempo real**
- Diseño accesible y pensado para ser usado bajo estrés
- Interfaz amigable y rápida
